ШАГ 1: Загрузите изменения на GitHub
────────────────────────────────────────────────────────────────

Откройте PowerShell и выполните:

cd C:\Users\User\source\repos\prop
git add .
git commit -m "Clean up .NET files, prepare for Railway deployment"
git push

ШАГ 2: Railway автоматически пересоберёт проект
────────────────────────────────────────────────────────────────

1. После git push зайдите на https://railway.app/
2. Откройте ваш проект consultant-crm
3. Railway увидит изменения и запустит новый деплой
4. Подождите 2-3 минуты

ШАГ 3: Проверьте успешный деплой
────────────────────────────────────────────────────────────────

1. В Railway перейдите в "Deployments"
2. Последний деплой должен быть зелёным ✅
3. Откройте "Deploy Logs" - не должно быть ошибок
4. Откройте ваш Railway URL (Settings → Generate Domain)
5. Должна открыться документация API: /docs
