## 🔄 Поток данных

### 1. Запрос данных (Read)
```
Браузер → JavaScript → HTTP GET → FastAPI main.py 
  → crud.py → models.py → SQLAlchemy → SQLite
  → Response (JSON) → JavaScript → Рендеринг HTML
```

### 2. Создание данных (Create)
```
Форма → JavaScript → Валидация → HTTP POST → FastAPI
  → schemas.py (валидация) → crud.py → models.py
  → SQLAlchemy → SQLite → Response → Обновление UI
```

### 3. Обновление данных (Update)
```
Кнопка "Редактировать" → Загрузка данных (GET)
  → Заполнение формы → Изменения → HTTP PUT/PATCH
  → Валидация → crud.py → Обновление БД
  → Response → Перезагрузка списка
```

### 4. Удаление данных (Delete)
```
Кнопка "Удалить" → Подтверждение → HTTP DELETE
  → crud.py → SQLAlchemy → Удаление из SQLite
  → Response → Обновление UI
```

## 🧩 Компоненты системы

### Frontend (Presentation Layer)

#### HTML страницы
- **Функция:** Структура и разметка
- **Технология:** HTML5, Bootstrap 5
- **Ответственность:** Layout, модальные окна, формы

#### CSS стили
- **Функция:** Визуальное оформление
- **Технология:** CSS3, Bootstrap 5, Custom CSS
- **Ответственность:** Корпоративный стиль, адаптивность

#### JavaScript модули
- **Функция:** Логика взаимодействия
- **Технология:** Vanilla JS (ES6+)
- **Ответственность:** 
  - Запросы к API
  - Рендеринг данных
  - Обработка событий
  - Валидация форм

### Backend (Business Logic + Data Layer)

#### main.py (API Layer)
- **Функция:** REST API endpoints
- **Технология:** FastAPI
- **Ответственность:**
  - Маршрутизация запросов
  - CORS настройка
  - Обработка ошибок
  - Dependency injection

#### schemas.py (Validation Layer)
- **Функция:** Валидация данных
- **Технология:** Pydantic
- **Ответственность:**
  - Схемы запросов/ответов
  - Валидация типов
  - Сериализация/десериализация

#### crud.py (Business Logic)
- **Функция:** Бизнес-логика
- **Технология:** Python
- **Ответственность:**
  - CRUD операции
  - Сложные запросы
  - Агрегация данных
  - Бизнес-правила

#### models.py (ORM Layer)
- **Функция:** Модели данных
- **Технология:** SQLAlchemy ORM
- **Ответственность:**
  - Определение таблиц
  - Связи между таблицами
  - Маппинг Python ↔ SQL

#### database.py (Database Layer)
- **Функция:** Подключение к БД
- **Технология:** SQLAlchemy Core
- **Ответственность:**
  - Engine создание
  - Session management
  - Connection pooling

### Database (Data Storage)

#### SQLite
- **Функция:** Хранение данных
- **Технология:** SQLite 3
- **Ответственность:**
  - Персистентность
  - ACID транзакции
  - Индексы и производительность

## 🔐 Безопасность

### Текущая реализация
- ✅ Валидация входных данных (Pydantic)
- ✅ SQL injection защита (SQLAlchemy ORM)
- ✅ CORS настройки
- ✅ Type hints для безопасности типов

### Будущие улучшения
- ⏳ JWT аутентификация
- ⏳ RBAC (Role-Based Access Control)
- ⏳ HTTPS/SSL
- ⏳ Rate limiting
- ⏳ Input sanitization
- ⏳ CSRF protection

## ⚡ Производительность

### Оптимизации
- ✅ Connection pooling (SQLAlchemy)
- ✅ Lazy loading (SQLAlchemy relationships)
- ✅ Пагинация списков
- ✅ Индексы на часто запрашиваемых полях
- ✅ Debouncing для поиска (500ms)

### Узкие места
- 🔴 SQLite - однопользовательская запись
- 🟡 Нет кэширования
- 🟡 Нет CDN для статики

### Рекомендации для масштабирования
1. Переход на PostgreSQL/MySQL
2. Добавить Redis для кэширования
3. Использовать CDN для frontend
4. Добавить load balancer
5. Контейнеризация (Docker)
6. Horizontal scaling с Kubernetes
