═══════════════════════════════════════════════════════════════
  📤 ШАГ 1: ЗАГРУЗИТЕ ИЗМЕНЕНИЯ НА GITHUB
═══════════════════════════════════════════════════════════════

Откройте PowerShell и выполните:

cd C:\Users\User\source\repos\prop
git add .
git commit -m "Update frontend API URLs for Railway"
git push

═══════════════════════════════════════════════════════════════
  🚀 ШАГ 2: ДЕПЛОЙ НА VERCEL
═══════════════════════════════════════════════════════════════

1. Откройте: https://vercel.com/

2. Нажмите "Sign Up" (если нет аккаунта)
   → "Continue with GitHub"

3. После входа нажмите "Add New" → "Project"

4. Выберите репозиторий: consultant-crm

5. В настройках проекта укажите:

   Framework Preset: Other
   ───────────────────────────
   
   Root Directory: frontend
   ───────────────────────────
   Нажмите "Edit" → введите "frontend" → Save
   
   Build Command:
   ───────────────────────────
   (оставьте пустым)
   
   Output Directory:
   ───────────────────────────
   ./
   
   Install Command:
   ───────────────────────────
   (оставьте пустым)

6. Нажмите "Deploy"

7. Подождите 1-2 минуты

8. Vercel создаст URL типа:
   consultant-crm.vercel.app

═══════════════════════════════════════════════════════════════
  🔧 ШАГ 3: НАСТРОЙТЕ CORS НА RAILWAY
═══════════════════════════════════════════════════════════════

1. Откройте Railway проект
2. Кликните на сервис consultant-crm
3. Перейдите в "Variables"
4. Нажмите "+ New Variable"
5. Добавьте:

   Variable name: ALLOWED_ORIGINS
   Value: https://consultant-crm.vercel.app,https://consultant-crm-git-main-ваш-username.vercel.app

   (замените на ваш реальный Vercel URL)

6. Railway автоматически перезапустит backend

═══════════════════════════════════════════════════════════════
  ✅ ШАГ 4: ПРОВЕРКА РАБОТЫ
═══════════════════════════════════════════════════════════════

1. Откройте ваш Vercel URL:
   https://consultant-crm.vercel.app

2. Вы должны увидеть:
   ✓ Синюю шапку "ООО Консульт"
   ✓ Меню: Дашборд | Клиенты | Заявки
   ✓ 3 карточки статистики
   ✓ Таблицу "Последние обращения"

3. Проверьте функциональность:
   → Перейдите в "Клиенты"
   → Нажмите "Добавить клиента"
   → Заполните форму и сохраните
   → Клиент должен появиться в списке!

═══════════════════════════════════════════════════════════════
  💾 ДОБАВЛЕНИЕ БАЗЫ ДАННЫХ POSTGRESQL
═══════════════════════════════════════════════════════════════

Для полноценной работы добавьте PostgreSQL:

1. В Railway откройте проект
2. Нажмите "+ New"
3. Выберите "Database"
4. Выберите "PostgreSQL"
5. Railway автоматически:
   - Создаст БД
   - Добавит переменную DATABASE_URL
   - Ваш backend подхватит её автоматически!

Готово! База данных работает! 🗄️

  🆘 РЕШЕНИЕ ПРОБЛЕМ
═══════════════════════════════════════════════════════════════

Frontend не загружается:
───────────────────────
• Проверьте Root Directory в Vercel = frontend
• Убедитесь, что файлы загружены на GitHub

Ошибки CORS:
───────────────────────
• Добавьте ALLOWED_ORIGINS в Railway Variables
• Укажите полный Vercel URL с https://

API не отвечает:
───────────────────────
• Проверьте, что Railway backend активен (зелёный статус)
• Откройте Railway URL + /docs для проверки
