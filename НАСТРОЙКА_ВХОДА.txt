После деплоя создайте первого администратора:

ВАРИАНТ 1: Через Railway Console
─────────────────────────────────

1. Откройте Railway проект:
   https://railway.app/project/3172147a-6f93-491d-b77d-9177ea355486

2. Кликните на сервис "consultant-crm"

3. Перейдите в "Settings" → прокрутите вниз

4. В разделе "Danger Zone" нажмите "Generate Console"

5. В открывшейся консоли выполните:

   python backend/create_user.py

6. Введите данные:
   - Имя пользователя: admin
   - Пароль: ваш_надёжный_пароль
   - Полное имя: Администратор

7. Готово! ✅


ВАРИАНТ 2: Через API документацию (проще)
──────────────────────────────────────────

1. Откройте Swagger документацию:
   https://consultant-crm-production.up.railway.app/docs

2. Найдите "POST /api/auth/register"

3. Нажмите "Try it out"

4. Введите JSON:
   {
     "username": "admin",
     "password": "ваш_пароль_123",
     "full_name": "Администратор"
   }

5. Нажмите "Execute"

6. Если увидите 201 Created - пользователь создан! ✅

7. ВАЖНО: После создания первого пользователя рекомендую
   отключить регистрацию или защитить её.


ВАРИАНТ 3: Локально (если есть доступ к БД)

python backend/create_user.py

═══════════════════════════════════════════════════════════════
  🔒 КАК ЭТО РАБОТАЕТ
═══════════════════════════════════════════════════════════════

1. При входе:
   ✓ Проверяется логин и пароль
   ✓ Создаётся JWT токен (срок действия 8 часов)
   ✓ Токен сохраняется в браузере

2. При каждом запросе:
   ✓ Токен автоматически добавляется к запросу
   ✓ Backend проверяет токен
   ✓ Если токен валиден - запрос выполняется
   ✓ Если нет - перенаправление на login

3. При выходе:
   ✓ Токен удаляется из браузера
   ✓ Перенаправление на страницу входа

4. Безопасность:
   ✓ Пароли хешируются (bcrypt)
   ✓ Токены подписаны криптографически
   ✓ Токены истекают через 8 часов

═══════════════════════════════════════════════════════════════
  🔐 ДОПОЛНИТЕЛЬНАЯ БЕЗОПАСНОСТЬ (ОПЦИОНАЛЬНО)
═══════════════════════════════════════════════════════════════

1. ОТКЛЮЧИТЕ РЕГИСТРАЦИЮ
   ────────────────────────
   После создания всех пользователей закомментируйте или
   удалите эндпоинт /api/auth/register в backend/app/main.py

2. СМЕНИТЕ SECRET_KEY
   ───────────────────
   В Railway добавьте переменную окружения:
   
   Имя: JWT_SECRET_KEY
   Значение: случайная строка (минимум 32 символа)
   
   Сгенерировать можно здесь:
   python -c "import secrets; print(secrets.token_urlsafe(32))"

   Затем обновите backend/app/auth.py:
   SECRET_KEY = os.getenv("JWT_SECRET_KEY", "fallback-key")

3. НАСТРОЙТЕ HTTPS ONLY
   ─────────────────────
   Убедитесь что frontend доступен только по HTTPS
   (Vercel делает это автоматически ✅)

4. НАСТРОЙТЕ ВРЕМЯ ЖИЗНИ ТОКЕНА
   ─────────────────────────────
   В backend/app/auth.py измените:
   ACCESS_TOKEN_EXPIRE_MINUTES = 480  # 8 часов (по умолчанию)
   
   Для большей безопасности можно сократить до 60 минут

Q: Забыл пароль, что делать?
A: Создайте нового пользователя через Railway Console или
   через API документацию, либо сбросьте пароль в БД.

Q: Токен истёк во время работы?
A: Просто войдите заново. Токен действует 8 часов.

Q: Можно ли добавить роли (админ/менеджер)?
A: Да, можно расширить модель User, добавив поле role.

Q: Как посмотреть всех пользователей?
A: Через Railway → PostgreSQL → Data → таблица users
   Или создайте эндпоинт GET /api/users

Q: Безопасно ли это?
A: Да! Используются industry-standard технологии:
   - bcrypt для паролей
   - JWT для токенов
   - HTTPS для передачи данных
