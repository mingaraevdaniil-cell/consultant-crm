═══════════════════════════════════════════════════════════════
  📦 ШАГ 1: ДОБАВЬТЕ POSTGRESQL В RAILWAY
═══════════════════════════════════════════════════════════════

1. Откройте ваш Railway проект:
   https://railway.app/project/3172147a-6f93-491d-b77d-9177ea355486

2. Нажмите "+ New" (справа сверху или в центре)

3. Выберите "Database"

4. Выберите "Add PostgreSQL"

5. Railway автоматически:
   ✓ Создаст базу данных
   ✓ Добавит переменную DATABASE_URL
   ✓ Свяжет её с вашим backend сервисом

6. Подождите 30 секунд

7. Railway автоматически перезапустит backend

8. Backend теперь использует PostgreSQL! ✅

═══════════════════════════════════════════════════════════════
  ✅ ПРОВЕРКА ПОДКЛЮЧЕНИЯ
═══════════════════════════════════════════════════════════════

1. В Railway кликните на сервис consultant-crm (не PostgreSQL!)

2. Перейдите в "Variables"

3. Вы должны увидеть переменную:
   DATABASE_URL = postgresql://postgres:...@...railway.app/railway

4. Откройте "Deployments"

5. В логах последнего деплоя должно быть:
   ✓ "Application startup complete"
   ✓ Без ошибок подключения к БД

═══════════════════════════════════════════════════════════════
  🧪 ТЕСТИРОВАНИЕ API С БАЗОЙ ДАННЫХ
═══════════════════════════════════════════════════════════════

1. Откройте API документацию:
   https://consultant-crm-production.up.railway.app/docs

2. Найдите endpoint "POST /api/clients"

3. Нажмите "Try it out"

4. Введите данные клиента:
   {
     "full_name": "Тестовый Клиент",
     "phone": "+7 999 123-45-67",
     "email": "test@test.ru"
   }

5. Нажмите "Execute"

6. Должен вернуться код 201 Created с данными клиента!

7. Проверьте GET /api/clients - клиент должен быть в списке!

═══════════════════════════════════════════════════════════════
  📊 ПРОСМОТР ДАННЫХ В БД
═══════════════════════════════════════════════════════════════

Через Railway:
────────────────

1. Кликните на PostgreSQL базу (не на consultant-crm!)
2. Перейдите в "Data"
3. Увидите таблицы: clients, requests
4. Можно просматривать записи прямо в интерфейсе!

Через psql (для продвинутых):
────────────────────────────────

1. В PostgreSQL перейдите в "Connect"
2. Скопируйте команду подключения
3. Выполните в терминале:
   psql postgresql://postgres:...@...railway.app/railway

4. Команды SQL:
   \dt              - список таблиц
   SELECT * FROM clients;
   SELECT * FROM requests;
