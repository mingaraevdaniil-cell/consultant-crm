## 🎯 Что это за приложение?

**Консульт CRM** - это современная веб-система для управления клиентами и заявками.

### Основные возможности:
- ✅ **Управление клиентами** - добавление, редактирование, поиск
- ✅ **Учёт заявок** - создание и отслеживание услуг
- ✅ **Дашборд** - статистика и аналитика в реальном времени
- ✅ **История взаимодействий** - полная информация по каждому клиенту
- ✅ **Адаптивный дизайн** - работает на ПК, планшетах и телефонах

---

## 🛠 Технологии

### Backend:
- **Python 3.8+** + **FastAPI** - быстрый и современный фреймворк
- **SQLAlchemy** - работа с базой данных
- **SQLite** - встроенная БД (можно переключиться на PostgreSQL)

### Frontend:
- **HTML5** + **Bootstrap 5** - адаптивный интерфейс
- **JavaScript** (Vanilla) - без лишних библиотек
- **REST API** - современная архитектура

## 📋 Требования

Для запуска нужно только:
- ✅ **Python 3.8 или выше**
- ✅ Современный браузер (Chrome, Firefox, Edge, Safari)

Проверьте Python:
```bash
python --version
# или
python3 --version
```

- **Windows:** https://www.python.org/downloads/
- **Linux:** `sudo apt install python3`
- **Mac:** `brew install python3`

## 🎓 Первые шаги

После запуска приложения:

### 1. Изучите дашборд
Откроется главная страница со статистикой (пока пустая).

### 2. Добавьте первого клиента
- Перейдите в раздел **"Клиенты"**
- Нажмите **"Добавить клиента"**
- Заполните форму (минимум ФИО и телефон)
- Сохраните

### 3. Создайте заявку
- Перейдите в раздел **"Заявки"**
- Нажмите **"Создать заявку"**
- Выберите клиента из списка
- Укажите тип услуги и стоимость
- Сохраните

### 4. Посмотрите статистику
Вернитесь на дашборд - теперь там будут данные!

## 🐛 Что-то не работает?

### Проверьте:

1. **Python установлен?**
   ```bash
   python --version
   ```

2. **Порты 8000 и 3000 свободны?**
   - Закройте другие приложения на этих портах
   - Или измените порты в скриптах

3. **Всё установлено?**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

4. **Сервер запущен?**
   - Backend должен быть на http://localhost:8000
   - Frontend должен быть на http://localhost:3000

### Ошибки CORS?
Убедитесь, что Frontend открыт через HTTP-сервер, а не через `file://`

### Всё равно не работает?
Смотрите детальное руководство: [QUICKSTART.md](QUICKSTART.md)
