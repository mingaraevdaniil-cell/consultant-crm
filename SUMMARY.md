## 🔌 API Endpoints

### Клиенты (7 endpoints)
```
GET    /api/clients          - Список клиентов
GET    /api/clients/count    - Количество
GET    /api/clients/{id}     - Получить клиента
POST   /api/clients          - Создать
PUT    /api/clients/{id}     - Обновить
DELETE /api/clients/{id}     - Удалить
```

### Заявки (5 endpoints)
```
GET    /api/requests         - Список заявок
GET    /api/requests/{id}    - Получить заявку
POST   /api/requests         - Создать
PATCH  /api/requests/{id}    - Обновить
DELETE /api/requests/{id}    - Удалить
```

### Статистика (1 endpoint)
```
GET    /api/dashboard        - Дашборд статистика
```

**Документация API:** http://localhost:8000/docs

## 💾 База данных

### Таблица: clients
```sql
id            INTEGER PRIMARY KEY
full_name     VARCHAR(255) NOT NULL
phone         VARCHAR(50) NOT NULL
email         VARCHAR(255)
company_name  VARCHAR(255)
notes         TEXT
created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
```

### Таблица: requests
```sql
id            INTEGER PRIMARY KEY
client_id     INTEGER NOT NULL (FK → clients.id)
service_type  VARCHAR(100) NOT NULL
status        VARCHAR(50) DEFAULT 'Новая'
price         FLOAT DEFAULT 0
description   TEXT
created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
```
