═══════════════════════════════════════════════════════════════
  ШАГ 1: ЗАГРУЗИТЕ ПРОЕКТ НА GITHUB (5 минут)
═══════════════════════════════════════════════════════════════

1️⃣ Откройте PowerShell:
   Win + R → введите "powershell" → Enter

2️⃣ Перейдите в папку проекта:
   cd C:\Users\User\source\repos\prop

3️⃣ Инициализируйте Git:
   git init
   git add .
   git commit -m "Initial commit - Consultant CRM"

4️⃣ Создайте репозиторий на GitHub:
   • Откройте https://github.com/
   • Войдите в аккаунт (или создайте новый)
   • Нажмите зелёную кнопку "New" (справа сверху)
   • Repository name: consultant-crm
   • Description: CRM для ООО Консульт
   • Public или Private (на ваш выбор)
   • НЕ добавляйте README, .gitignore, license
   • Нажмите "Create repository"

5️⃣ Загрузите код (замените YOUR_USERNAME на ваш username):
   git remote add origin https://github.com/YOUR_USERNAME/consultant-crm.git
   git branch -M main
   git push -u origin main

   Если попросит логин:
   - Username: ваш GitHub username
   - Password: создайте Personal Access Token:
     https://github.com/settings/tokens
     → Generate new token (classic)
     → Выберите repo
     → Generate token
     → Скопируйте токен и используйте вместо пароля

═══════════════════════════════════════════════════════════════
  ШАГ 2: РАЗВЕРНИТЕ BACKEND НА RAILWAY (3 минуты)
═══════════════════════════════════════════════════════════════

1️⃣ Откройте https://railway.app/

2️⃣ Нажмите "Login" → "Login with GitHub"
   Войдите через ваш GitHub аккаунт

3️⃣ Нажмите "New Project"

4️⃣ Выберите "Deploy from GitHub repo"

5️⃣ Railway спросит доступ к GitHub → разрешите
   (Configure GitHub App → выберите consultant-crm репозиторий)

6️⃣ Выберите репозиторий "consultant-crm"

7️⃣ Railway автоматически начнёт деплой!
   Подождите 2-3 минуты

8️⃣ Добавьте базу данных PostgreSQL:
   • В проекте нажмите "+ New"
   • Выберите "Database"
   • Выберите "PostgreSQL"
   • Railway создаст БД автоматически!

9️⃣ Получите URL вашего backend:
   • Кликните на сервис backend (не на PostgreSQL!)
   • Перейдите в "Settings"
   • Найдите "Public Networking"
   • Нажмите "Generate Domain"
   • Railway создаст URL типа:
     consultant-crm-production.up.railway.app

🔥 СОХРАНИТЕ ЭТОТ URL! Он понадобится для frontend!

🔟 Проверьте работу:
   Откройте: https://ваш-домен.up.railway.app/docs
   Должна открыться API документация!

═══════════════════════════════════════════════════════════════
  ШАГ 3: ОБНОВИТЕ FRONTEND ДЛЯ RAILWAY (2 минуты)
═══════════════════════════════════════════════════════════════

1️⃣ Откройте файлы в папке frontend/js/:
   - dashboard.js
   - clients.js  
   - requests.js

2️⃣ В каждом файле найдите строку:
   const API_URL = window.location.hostname === 'localhost'

   И замените весь блок на:

   const API_URL = window.location.hostname === 'localhost' 
       ? 'http://localhost:8000/api'
       : 'https://ВАШ-RAILWAY-ДОМЕН.up.railway.app/api';

   ⚠️ ЗАМЕНИТЕ ВАШ-RAILWAY-ДОМЕН на домен из шага 2-9!

3️⃣ Сохраните файлы

4️⃣ Загрузите изменения на GitHub:
   git add .
   git commit -m "Update API URL for Railway"
   git push

═══════════════════════════════════════════════════════════════
  ШАГ 4: РАЗВЕРНИТЕ FRONTEND НА VERCEL (2 минуты)
═══════════════════════════════════════════════════════════════

1️⃣ Откройте https://vercel.com/

2️⃣ Нажмите "Sign Up" → "Continue with GitHub"

3️⃣ Нажмите "Add New" → "Project"

4️⃣ Выберите репозиторий "consultant-crm"

5️⃣ В настройках:
   • Framework Preset: Other
   • Root Directory: frontend (ВАЖНО!)
   • Build Command: (оставьте пустым)
   • Output Directory: ./ (точка слэш)

6️⃣ Нажмите "Deploy"

7️⃣ Подождите 1-2 минуты

8️⃣ Vercel создаст URL типа:
   consultant-crm.vercel.app

═══════════════════════════════════════════════════════════════
  ШАГ 5: НАСТРОЙТЕ CORS (1 минута)
═══════════════════════════════════════════════════════════════

1️⃣ В Railway откройте проект backend

2️⃣ Перейдите в "Variables"

3️⃣ Нажмите "+ New Variable"

4️⃣ Добавьте:
   Variable name: ALLOWED_ORIGINS
   Value: https://consultant-crm.vercel.app
   
   (замените на ваш Vercel URL из шага 4-8)

5️⃣ Railway автоматически перезапустит backend
