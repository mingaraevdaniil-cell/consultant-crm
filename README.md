# 🏢 Консульт CRM - Система учёта клиентов

Полноценное веб-приложение для учёта клиентов и управления заявками компании **ООО Консульт**.

## 📋 Описание

Современная CRM-система с интуитивным интерфейсом, позволяющая:
- Управлять базой клиентов
- Создавать и отслеживать заявки на услуги
- Просматривать статистику и аналитику
- Контролировать доходы от завершённых услуг

## 🛠 Стек технологий

### Backend
- **Python 3.8+**
- **FastAPI** - современный асинхронный веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite** - встроенная база данных
- **Pydantic** - валидация данных

### Frontend
- **HTML5** - разметка
- **Bootstrap 5** - адаптивный дизайн
- **Vanilla JavaScript** - функциональность
- **Bootstrap Icons** - иконки

## 🚀 Установка и запуск

### Шаг 1: Клонирование репозитория
```bash
# Если проект в Git
git clone <repository-url>
cd consultant-crm
```

### Шаг 2: Установка Python зависимостей

Убедитесь, что у вас установлен **Python 3.8+**:
```bash
python --version
```

Установите зависимости:
```bash
cd backend
pip install -r requirements.txt
```

### Шаг 3: Запуск Backend сервера

Из папки `backend` выполните:
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Параметры:**
- `--reload` - автоматическая перезагрузка при изменении кода
- `--host 0.0.0.0` - доступ с любого IP
- `--port 8000` - порт сервера

✅ Backend запущен на: `http://localhost:8000`  
📖 API документация (Swagger): `http://localhost:8000/docs`

### Шаг 4: Запуск Frontend

Фронтенд работает через любой HTTP-сервер. Варианты:

#### Вариант 1: Python HTTP сервер (рекомендуется)
```bash
cd frontend
python -m http.server 3000
```

#### Вариант 2: Node.js http-server
```bash
cd frontend
npx http-server -p 3000
```

#### Вариант 3: Live Server (VS Code расширение)
Откройте `frontend/index.html` в VS Code и нажмите "Go Live"

✅ Frontend доступен на: `http://localhost:3000`

### Шаг 5: Открытие приложения

Откройте в браузере:
```
http://localhost:3000/index.html
```

## 📊 База данных

При первом запуске автоматически создаётся файл БД `consultant_crm.db` в папке `backend/`.

### Структура БД

**Таблица `clients` (Клиенты):**
- `id` - уникальный идентификатор
- `full_name` - ФИО клиента
- `phone` - телефон
- `email` - электронная почта
- `company_name` - название компании
- `notes` - заметки
- `created_at` - дата создания записи

**Таблица `requests` (Заявки):**
- `id` - уникальный идентификатор
- `client_id` - ID клиента (внешний ключ)
- `service_type` - тип услуги
- `status` - статус (Новая, В работе, Завершена, Отменена)
- `price` - стоимость
- `description` - описание
- `created_at` - дата создания

## 🎯 Основные функции

### 1. Дашборд
- **Статистика:** общее количество клиентов, активные заявки, суммарный доход
- **Последние обращения:** таблица с последними 5 заявками

### 2. Управление клиентами
- Просмотр списка клиентов с пагинацией
- Поиск по ФИО, телефону или email
- Добавление нового клиента
- Редактирование данных клиента
- Просмотр карточки клиента с историей заявок
- Удаление клиента

### 3. Управление заявками
- Создание заявки для клиента
- Быстрое изменение статуса через выпадающий список
- Редактирование заявки
- Фильтрация по статусу
- Удаление заявки

## 🔌 API Endpoints

### Клиенты
- `GET /api/clients` - список клиентов (пагинация, поиск)
- `GET /api/clients/count` - количество клиентов
- `GET /api/clients/{id}` - получить клиента с заявками
- `POST /api/clients` - создать клиента
- `PUT /api/clients/{id}` - обновить клиента
- `DELETE /api/clients/{id}` - удалить клиента

### Заявки
- `GET /api/requests` - список заявок (фильтрация)
- `GET /api/requests/{id}` - получить заявку
- `POST /api/requests` - создать заявку
- `PATCH /api/requests/{id}` - обновить заявку
- `DELETE /api/requests/{id}` - удалить заявку

### Статистика
- `GET /api/dashboard` - статистика для дашборда

## 🔧 Настройка

### Изменение порта Backend
Измените параметр `--port` при запуске:
```bash
uvicorn app.main:app --reload --port 8080
```

И обновите `API_URL` в JS файлах:
```javascript
const API_URL = 'http://localhost:8080/api';
```

### Переход на PostgreSQL

1. Установите драйвер:
```bash
pip install psycopg2-binary
```

2. Измените `backend/app/database.py`:
```python
SQLALCHEMY_DATABASE_URL = "postgresql://user:password@localhost/consultant_crm"
engine = create_engine(SQLALCHEMY_DATABASE_URL)
```

## 🐛 Решение проблем

### CORS ошибки
Если возникают ошибки CORS, убедитесь что:
- Backend запущен на порту 8000
- Frontend открыт через HTTP сервер (не через file://)

### База данных не создаётся
Проверьте права на запись в папке `backend/`

### Не загружаются стили
Проверьте пути в HTML файлах, они должны быть относительными
