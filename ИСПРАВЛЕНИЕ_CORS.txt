Если хотите настроить дополнительные домены:

1. Откройте Railway проект:
   https://railway.app/project/3172147a-6f93-491d-b77d-9177ea355486

2. Кликните на сервис "consultant-crm"

3. Перейдите в раздел "Variables"

4. Нажмите "+ New Variable"

5. Добавьте:
   
   Имя:     ALLOWED_ORIGINS
   
   Значение: https://consultant-crm-frontend.vercel.app

   (можно добавить несколько через запятую)

6. Нажмите "Add"

7. Railway автоматически перезапустит сервер

═══════════════════════════════════════════════════════════════
  ШАГ 3: ПРОВЕРКА
═══════════════════════════════════════════════════════════════

1. Подождите 1-2 минуты пока Railway завершит деплой

2. Проверьте логи деплоя в Railway:
   - Кликните на сервис "consultant-crm"
   - Откройте "Deployments"

   - В логах должно быть:
     ✓ "Application startup complete"

   https://consultant-crm-frontend.vercel.app

4. Откройте DevTools (F12) → Console

5. Обновите страницу (Ctrl+R или F5)

6. В консоли должны увидеть:
   ✓ "Загружена статистика: ..."
   ✓ БЕЗ красных ошибок CORS

7. Попробуйте добавить клиента:
   - Нажмите "Клиенты" → "Добавить клиента"
   - Заполните форму
   - Нажмите "Сохранить"
   - Клиент должен появиться в списке! ✅

═══════════════════════════════════════════════════════════════
  🔍 ЧТО Я ИСПРАВИЛ
═══════════════════════════════════════════════════════════════

В файле backend/app/main.py:

БЫЛО:
------
allow_origins=["*"]  ← это не работает с credentials

СТАЛО:
------
allow_origins=[
    "https://consultant-crm-frontend.vercel.app",  ← ваш frontend
    "http://localhost:8000",                        ← для разработки
    "http://127.0.0.1:8000",                       ← для разработки
]

Теперь backend точно знает, с каких доменов принимать запросы!
