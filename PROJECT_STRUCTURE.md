## 🗂 Описание ключевых файлов

### Backend

#### `main.py` (430+ строк)
- Главный файл FastAPI приложения
- Определяет все REST API endpoints
- Настраивает CORS
- Автоматически создаёт таблицы БД

#### `models.py` (40+ строк)
- SQLAlchemy модели
- `Client` - модель клиента (7 полей)
- `Request` - модель заявки (7 полей + связь с Client)

#### `schemas.py` (60+ строк)
- Pydantic схемы для валидации
- Схемы для создания и обновления данных
- Схемы для ответов API

#### `crud.py` (180+ строк)
- CRUD операции (Create, Read, Update, Delete)
- Функции для работы с клиентами
- Функции для работы с заявками
- Функция получения статистики

#### `database.py` (30+ строк)
- Конфигурация SQLite БД
- Создание engine и session
- Dependency injection для FastAPI

## 🌐 API Endpoints

### Клиенты (7 endpoints)
- `GET    /api/clients` - список
- `GET    /api/clients/count` - количество
- `GET    /api/clients/{id}` - получить
- `POST   /api/clients` - создать
- `PUT    /api/clients/{id}` - обновить
- `DELETE /api/clients/{id}` - удалить

### Заявки (5 endpoints)
- `GET    /api/requests` - список
- `GET    /api/requests/{id}` - получить
- `POST   /api/requests` - создать
- `PATCH  /api/requests/{id}` - обновить
- `DELETE /api/requests/{id}` - удалить

### Статистика (1 endpoint)
- `GET    /api/dashboard` - дашборд

## 💾 База данных

### SQLite файл
- `consultant_crm.db` - основная БД (создаётся автоматически)

### Таблицы
1. **clients** (7 полей)
   - id, full_name, phone, email, company_name, notes, created_at

2. **requests** (7 полей + FK)
   - id, client_id, service_type, status, price, description, created_at

### Связи
- Request.client_id → Client.id (Foreign Key)
- Каскадное удаление заявок при удалении клиента
